# projects/ — the public workshop of High on Intelligence

Everything in this directory is a standalone project merged into this repository with
`git subtree`. Histories are preserved verbatim (`git log -- projects/<name>`).

| Path | What it is | Upstream |
| --- | --- | --- |
| `projects/nine-room` | Premium nine-ball billiards for the browser (JS, physics, HUD) | github.com/hazem-soussi-HA/nine-room |
| `projects/amazon-expedition-3d` | First-person 3D jungle expedition (three.js) | github.com/hazem-soussi-HA/amazon-expedition-3d |
| `projects/hazoom-dj-techno` | Generative techno engine in pure DSP + TRANSISTOR live studio + **HAZOOM FM** (web radio: official YouTube 24/7 streams + Aethric renders) | github.com/hazem-soussi-HA/hazoom-dj-techno |
| `projects/lumen-studio` | Browser-native 3D engine & editor (WebGL / OpenGL ES) | github.com/hazem-soussi-HA/lumen-studio |

- All projects are MIT-licensed, run 100% client-side, and carry zero trackers.
- The public site serves them from GitHub Pages under `/projects/<name>/`.
- Entry points: `nine-room/index.html`, `amazon-expedition-3d/index.html`,
  `hazoom-dj-techno/transistor-studio.html`, `hazoom-dj-techno/hazoom-fm.html`, `lumen-studio/index.html`.
- A floating `HOI` badge in each entry page links back to `/services.html`.
- Changes to a project are made here; upstream repos are historical mirrors.

See `../services.html` for the public hub.
